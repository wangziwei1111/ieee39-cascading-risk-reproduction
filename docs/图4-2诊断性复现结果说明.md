# 图4-2诊断性复现结果说明

## 1. 图4-2复现目的

该图用于对比无新能源接入和节点30至39分散式接入3000MW新能源时，连锁故障风险指标LLR、LFOR、NVOR的概率密度分布。其目标是观察新能源接入前后事故链风险分布形态和尾部风险水平是否发生变化。

需要强调的是，本图是公开信息约束下的诊断性复现结果。由于原文未公开完整IEEE39改造算例、保护和隐性故障统计参数、CloudPSS模型细节以及Markov抽样策略，因此本图不应称为严格复现原文图4-2。

## 2. 场景设置

场景1为无新能源接入场景：

- 无新能源接入；
- 所有发电机按传统机组处理；
- `scenario_id = fig4_2_no_renewable`。

场景2为分散式新能源接入场景：

- 节点30至39分散式接入新能源；
- 总新能源容量3000MW；
- 使用`paper_2_12_20`风电曲线；
- `scenario_id = fig4_2_distributed_renewable_3000MW`。

两个场景均输出事故链样本、风险样本、概率密度数据和图像。该对比仅用于公开信息约束下的诊断分析，不作为原文严格数值复现结论。

## 3. 公式与指标设置

本轮图4-2诊断性复现使用当前已经确认或固化的公开公式链路：

- 线路停运概率聚合形式：`P_L = P1 + P2 + P3`；
- 潮流相关故障概率：`P_flow`论文分段公式；
- 潮流越限隐性故障概率：`P_HF_L`论文分段公式；
- 事故链转移概率：full-event Bernoulli链概率；
- 终止阶段概率处理：terminal-aware概率处理；
- 严重度公式：`paper_confirmed_exponential_sum`；
- 主体指标：LLR、LFOR、NVOR；
- CRI仅作为参考指标，不作为图4-2主体指标。

其中保护拒动、断路器误动、隐性故障等统计参数仍属于反向校准或诊断假设参数，不是原文公开参数。

## 4. 样本与风险值构造

每个场景生成多条事故链样本。本轮采用20 trials / initial branch的诊断设置，用于控制桌面环境运行时间；该设置不低于任务要求的最小样本数10。

每条事故链的风险样本按以下形式构造：

```text
R_metric = initial_line_probability * chain_transition_probability * basic_metric
```

其中`metric`对应LLR、LFOR或NVOR。为了与前期VaR显示口径保持一致，图中显示列使用：

```text
R_metric_display = R_metric / 1e-4
```

零风险样本被完整保留，不因绘图而删除。概率密度曲线优先使用KDE估计；当样本过少或样本退化时，退化为直方图密度估计，并保留完整取值范围。

## 5. 结果统计

根据`fig4_2_metric_summary.csv`，无新能源接入场景的关键p95结果如下：

- LLR p95 = 0.5243；
- LFOR p95 = 0.4777；
- NVOR p95 = 0.4741；
- CRI_reference p95 = 0.6940。

节点30至39分散式接入3000MW新能源场景的关键p95结果如下：

- LLR p95 = 1.6055；
- LFOR p95 = 1.9555；
- NVOR p95 = 1.5597；
- CRI_reference p95 = 1.9537。

从当前诊断样本看，新能源接入后LLR、LFOR、NVOR的均值和p95均高于无新能源接入场景，风险分布整体向高风险方向移动。这说明在当前公开信息和诊断参数约束下，新能源接入改变了事故链风险分布，并提高了尾部风险水平。

上述结论只反映当前诊断模型和参数设定下的趋势，不应外推为原文严格数值结论。
