# 严格复现所需补充资料清单

| 资料名称 | 为什么需要 | 缺失会造成什么影响 | 优先级 | 可替代方案 |
|---|---|---|---|---|
| IEEE39 改造后算例数据 | 确认母线、机组、负荷和线路参数 | 所有潮流和风险数值可能偏离 | 高 | 使用 MATPOWER case39 并明确诊断假设 |
| 线路限额 | 影响 LFOR、P_flow 和 P_L | 线路越限概率和严重度不可严格对齐 | 高 | 使用 RATE_A 或默认容量并标记近似 |
| 表 4-6 各风速下常规机组 PG | 确认风速变化后的调度方式 | 无法判断 12 m/s 风险降低机制 | 最高 | 做 sensitivity，但不能称为论文复现 |
| 表 4-6 各风速下风电实际吸收功率 | 区分可发功率和实际消纳功率 | 可能误判弃风或消纳策略 | 最高 | 用风电曲线输出作为诊断假设 |
| slack 母线/平衡机组 | 决定功率不平衡由谁承担 | 基础潮流分布可能完全不同 | 高 | 使用 bus31 并标记未确认 |
| 是否弃风 | 12 m/s 是否满发会影响潮流 | 风速趋势可能被错误解释 | 高 | 设计 fixed absorbed power sensitivity |
| 各风速基础潮流 | 直接验证运行点 | 无法确认 baseflow-driven tail 是否来自模型差异 | 最高 | 仅比较当前 PF 结果 |
| 各风速线路 loading | 直接影响 P_L 和 LFOR | 无法严格复现线路风险 | 最高 | 由当前模型计算并标记诊断 |
| 原文停运概率参数 | P_W_D、P_L_D、P_L_r 等影响概率 | 只能 benchmark-calibrated，不能称原文参数 | 高 | 参数敏感性分析 |
| Markov 抽样数量和随机策略 | 影响 VaR 稳定性和可比性 | 趋势可能受样本差异影响 | 中 | common random diagnostic |
| 是否固定事故链样本 | 决定风速扫描是否可配对比较 | 无法判断趋势差异来源 | 中 | 使用 paired diagnostic 并说明 |
| CloudPSS 模型文件 | 可直接复现作者算例 | 缺少运行点、保护参数和调度细节 | 最高 | 公开信息复现骨架 |
